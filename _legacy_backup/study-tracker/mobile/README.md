# Mobile APK Distribution

## Overview

This directory contains the production Android APK that is **automatically built and deployed** via CI/CD.

## 🤖 Automated Build Process

When you push to the `main` branch, GitHub Actions automatically:

1. ✅ Builds the `frontend-web` app with **production API URL** from `EC2_HOST` secret
2. ✅ Syncs code with Capacitor
3. ✅ Compiles the Android APK using Gradle
4. ✅ Places the APK in this directory
5. ✅ Includes APK in Docker image
6. ✅ Deploys to EC2

**No manual intervention required!** The APK is always up-to-date with your latest code.

## Configuration

The APK automatically connects to your production backend:

```bash
VITE_API_URL=http://${{ secrets.EC2_HOST }}/trackapp/api
```

- Uses `EC2_HOST` from GitHub repository secrets
- No hardcoded IPs in the code
- Fully automated and secure

## Download URL

Users can download the APK from:

- **Production:** `http://<YOUR_EC2_IP>/trackapp/app-release.apk`
- **Local Dev:** `http://localhost:3000/trackapp/app-release.apk`

The APK is served with filename: `TaskTracker.apk`

## Manual Build (Optional)

If you need to build locally with a custom backend URL:

```bash
# From repository root
cd frontend-web

# Set your backend URL
export VITE_API_URL=http://YOUR_SERVER/trackapp/api

# Install and build
npm install
npm run build
npx cap sync android

# Build APK
cd android
./gradlew assembleRelease

# APK location: android/app/build/outputs/apk/release/app-release-unsigned.apk
```

## Health Check

Check deployment status:
```bash
curl http://<YOUR_EC2_IP>/trackapp/health
```

Response includes APK download URL:
```json
{
  "status": "OK",
  "message": "Study Tracker API is running",
  "database": "Neon PostgreSQL",
  "apk_download": "/trackapp/app-release.apk"
}
```

## Notes

- APK rebuilds on every push to `main` branch
- Always uses latest `EC2_HOST` from GitHub Secrets
- Build time adds ~5 minutes to CI/CD pipeline
- APK is unsigned (users need to enable "Install from unknown sources")
